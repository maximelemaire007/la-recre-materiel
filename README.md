# La Récré : matériel pédagogique

Ce dépôt contient le travail de conception des ressources La Récré : plans, textes, PDF exportés et aperçus. Les designs eux-mêmes sont créés dans Canva.

## Méthode de travail

1. **Le besoin** est reformulé : public, matière, objectif pédagogique, liste des pages et format. On pose les questions s'il manque une information.
2. **Le plan et le contenu** (textes, questions, corrigé) sont rédigés dans `ressources/<ressource>/plan.md`, puis validés par la créatrice.
3. **La réalisation** se fait dans Canva, à partir des gabarits du dossier « La Récré – Gabarits Claude », avec le kit de marque « La Récré ». Un design existant ne sert jamais directement : on travaille toujours sur une copie.
4. **La vérification** porte sur :
   - l'orthographe québécoise ;
   - la lisibilité pour le niveau visé ;
   - le contraste ;
   - des marges d'au moins 0,5 po ;
   - l'absence de débordement ;
   - le logo en bas à droite ;
   - les polices du kit.
5. **L'exportation** produit un PDF pour l'impression, et une version noir et blanc quand c'est pertinent. Une copie du PDF est rangée dans le dossier de la ressource.
6. **Les aperçus boutique** (1080 × 1350 px, en PNG) sont accompagnés d'une fiche produit.
7. **Le dépôt** reçoit le travail poussé, ainsi que le lien vers le design Canva.

La référence de marque est `BRAND.md`, dans le dépôt `la-recre-theme` (lecture seule).

## Organisation des dossiers

- `gabarits/` : exports des gabarits réutilisables (PDF et PNG).
- `ressources/<nom-de-la-ressource>/` : un dossier par ressource, qui contient :
  - `plan.md` ;
  - les textes ;
  - les PDF ;
  - les aperçus PNG ;
  - `canva.md`, avec les liens vers les designs.
